🏦 Banco Escolar Digital

Projeto desenvolvido para a avaliação prática da disciplina de **Programação Web 2**, do curso Técnico em Desenvolvimento de Sistemas.

📌 Sobre o projeto

O objetivo da atividade foi completar um sistema bancário já iniciado, implementando funções de depósito, saque e transferência entre contas, utilizando JavaScript.

⚙️ Funcionalidades

- Cadastro de contas comuns e especiais.
- Depósitos e saques com validações.
- Transferências entre contas bancárias.
- Controle de saldo e limite de crédito.
- Histórico de movimentações com data e hora.
- Mensagens de sucesso e erro.

💻 Tecnologias utilizadas

- **HTML5:** estrutura das páginas.
- **CSS3:** estilização da interface.
- **JavaScript:** lógica das operações e validações.
